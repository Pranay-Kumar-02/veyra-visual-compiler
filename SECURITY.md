# Security Policy

## Supported Versions

Security updates and patches are provided for the active release branch:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x (Phase 1) | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security of Veyra Visual Compiler seriously. If you discover a potential vulnerability or security flaw, please report it responsibly:

1. **Do not open a public GitHub issue** for sensitive security vulnerabilities.
2. Contact the maintainer directly with details of the vulnerability.
3. Provide a clear description of the vulnerability, including:
   - Reproduction steps or proof-of-concept code
   - Potential impact
   - Affected system components (e.g. parser, interpreter runtime, REST API)
4. You will receive an acknowledgement within 48 hours, followed by updates on the fix and timeline.
